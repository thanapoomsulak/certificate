Blockchain Certificate Verification

ตรวจสอบใบรับรองได้ทันที
ไม่ต้องโทรถาม ไม่ต้องรอเอกสาร

ทุกใบรับรองของ SkillTrust Academy ถูกบันทึกหลักฐานไว้บน Ethereum Smart Contract กรอกรหัสใบรับรองหรือสแกน QR Code เพื่อดูสถานะจริงจาก Blockchain — ไม่ต้องเชื่อมต่อ Wallet

01

ป้องกันการแก้ไขเอกสาร

Hash ของข้อมูลและไฟล์ PDF ถูกเก็บบน Blockchain แก้แม้แต่ตัวอักษรเดียว Hash ก็ไม่ตรง

02

รู้สถานะปัจจุบันทันที

ใบรับรองที่ถูกเพิกถอนจะแสดงสถานะ “ถูกเพิกถอน” พร้อมเหตุผล ประวัติการออกยังคงอยู่

03

ไม่เปิดเผยข้อมูลส่วนบุคคล

ชื่อผู้รับไม่ถูกบันทึกบน Public Blockchain ผู้ตรวจต้องรู้ชื่อบนใบรับรองจึงยืนยันได้

วิธี deploy Smart Contract (Remix + MetaMask)
  1. เปิด remix.ethereum.org แล้วสร้างไฟล์ SkillTrustCertificates.sol จากโฟลเดอร์ contracts/ ของ repo นี้
  2. Compile ด้วย Solidity 0.8.20 ขึ้นไป
  3. แท็บ Deploy เลือก Environment “Injected Provider - MetaMask” (เครือข่าย Hoodi) แล้วกด Deploy
  4. คัดลอก Address ของสัญญามาใส่ที่ช่องด้านบน หรือแก้ใน js/config.js
